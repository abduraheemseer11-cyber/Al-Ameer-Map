# Scanner Wireless — ماسح الشبكة اللاسلكية

تطبيق أندرويد (Kotlin + Jetpack Compose + Hilt + Room) لفحص الشبكة المحلية، مستوحى من تطبيق Fing.

## البناء عبر GitHub Actions (بدون Android Studio)

1. أنشئ مستودعاً جديداً على GitHub (فارغاً).
2. ارفع محتويات هذا المجلد كما هي (بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions** ← سير العمل **Build Android APK** (يبدأ تلقائياً عند أول push).
4. بعد نجاح البناء افتح التشغيل ← قسم **Artifacts** ← حمّل **ScannerWireless-debug-apk**.
5. فك الضغط وثبّت ملف `app-debug.apk` على هاتفك (فعّل «التثبيت من مصادر غير معروفة»).

## الفتح في Android Studio
افتح المجلد مباشرة؛ سيُنشئ Android Studio ملفات Gradle Wrapper تلقائياً.
أو نفّذ `gradle wrapper --gradle-version 8.9` ثم `./gradlew assembleDebug`.

## ما الذي يعمل
- لوحة القيادة: دائرة متحركة، زر فحص، حالة الشبكة، آخر سرعة، تنبيهات الأجهزة الجديدة.
- فحص الأجهزة (Ping + منافذ شائعة + اسم المضيف + مصنّع MAC عبر macvendors.com).
- اختبار السرعة (تحميل/رفع/زمن استجابة عبر Cloudflare).
- أدوات: Ping، Traceroute، DNS، فحص المنافذ، Wake on LAN، كشف الكاميرات.
- حفظ الأجهزة المعروفة في Room وإشعار عند ظهور جهاز جديد.
- العربية افتراضياً مع RTL، والإنجليزية في `values-en`.

## قيود معروفة
- أندرويد 10+ يمنع قراءة جدول ARP، لذلك عناوين MAC للأجهزة الأخرى (والمصنّع) تظهر غالباً فقط على أجهزة Root.
- الميزات المتقدمة (الحضور الرقمي، الحظر، الرقابة الأبوية…) معروضة كـ «قريباً» في الإعدادات.
